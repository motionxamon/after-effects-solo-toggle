# Embedded S icon

Generated with the built-in OpenAI image generation tool. The resulting PNG was resized to 40 × 40 pixels for ScriptUI and encoded as a binary JavaScript string in `Solo_Toggle_Panel.jsx`.

Prompt:

> Create a single minimal square toolbar button icon for Adobe After Effects Solo Toggle. UI icon asset, flat crisp graphic, not a product mockup. One large uppercase letter "S" exactly, bold clean geometric sans serif, optically centered. White S on a solid charcoal dark gray square with subtly rounded corners, restrained thin medium gray edge. S occupies about 60 percent of square height, generous balanced padding. High contrast, highly legible at 32px. Straight front view, no perspective, no drop shadow outside button, no glow, no extra symbols, no other text, no watermark. Square image, button fills the canvas edge to edge.

The source PNGs in this folder are for preview/rebuilding only. Installing either JSX does not require this folder. The image is embedded as bytes in JSX; a JSXBIN compiler is not required.
